# Contributing

Corrections are the most useful contribution. Prices and exit program conditions live in the
[EU Cloud Price Index](https://github.com/moveinfra/eu-cloud-prices) (`data/manual.json`); please correct them there,
with a link to the provider page. Changes to the notice or the Data Act wording: open an issue with the article you
rely on.

Code: plain ES modules, no dependencies. Run `npm test` before opening a pull request.
